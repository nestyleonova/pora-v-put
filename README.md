# Пора в путь — итоговый проект по фронтенду

Лендинг туристического портала: короткие маршруты выходного дня по России. Учебный проект по дисциплине «Фронтенд-разработка для веб-дизайнеров: HTML, CSS, JavaScript».

- **Демо:** https://nestyleonova.github.io/pora-v-put/
- **Код:** https://github.com/nestyleonova/pora-v-put

## Что внутри

Одностраничный сайт из пяти экранов прокрутки (требование итогового задания — минимум пять):

1. Первый экран с фоновым фото и статистикой.
2. «Маршруты» — три карточки направлений в CSS Grid.
3. «Как это работает» — четыре шага.
4. «Отзывы» — два отзыва.
5. CTA-блок с формой подписки.

Плюс общий подвал. Меню `sticky`, мобильное бургер-меню, форма с сообщением об успехе, адаптив до 600 px.

## Структура

```
index.html        разметка страницы
css/style.css     стили: Grid, Flexbox, sticky/absolute, медиазапросы
js/main.js        бургер-меню и обработка формы
img/              фотографии маршрутов
```

## Локальный просмотр

Сборка не нужна, сайт статический:

```
python -m http.server 8124
```

Открыть `http://127.0.0.1:8124/`.
